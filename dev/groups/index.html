Groups

Groups categorize the problems in Matrix Depot. Group names are symbols, e.g. :symmetric, and can be used as patterns anywhere a pattern is accepted. listgroups returns all defined groups.

Predefined groups

groupmeaning
:allall problems in the collection
:builtinlocally generated built-in problems
:useruser-defined generators, see User Generators
:local:builtin and :user
:eigenpart of the eigensystem is explicitly known
:graphadjacency matrix of a graph
:illcondill-conditioned for some parameter values
:inversethe inverse is known explicitly
:orthogonalthe matrix is orthogonal
:posdefpositive definite for some parameter values
:randomthe matrix has random entries
:regprobtest problem for regularization methods
:sparsethe matrix is sparse
:symmetricsymmetric for some parameter values

User-defined groups

setgroup! defines a new group from any pattern, not only from lists of names, and deletegroup! removes it again:

setgroup!(:myfav, ["lehmer", "cauchy", "hilb"])
setgroup!(:spd, :symmetric & :posdef)
mdlist(:myfav)
3-element Vector{String}:
 "cauchy"
 "hilb"
 "lehmer"
deletegroup!(:myfav)
deletegroup!(:spd)
